### 默认多 Agent 协作与委派（自动生效）
- **默认分工**：主会话（Neon）专注于需求澄清、方案设计、上下文提炼与独立验收，不亲自硬扛体力活；细微杂活、代码库大范围检索/摘要、中小型改动、多文件实现或并行子任务，**默认主动加载并执行 `multi-agent-delegation` Skill** 下沉给 `AGY Hydrogen` / `Claude Code GLM-5.3-Flash`，无需用户每次显式提醒。
- **例外与升级**：仅极小单点改动（数行以内、无探索成本）由主会话直接完成；便宜模型连续 2–3 轮自修仍不绿时熔断升级 `Sonnet 5.5`；高风险架构或复杂权衡先由主会话提炼高密度上下文，再主动建议调用少量 `Opus 5.5` 额度联合决策。
- **配额降级与会话复用**：若 Cursor 或 Claude Code (GLM) 额度耗尽/报错，自动降级为全员 `AGY Hydrogen`（或原生 subagent）兜底，并在本会话内熔断故障通道；同主题/同模块多轮任务优先复用已有 subagent（`send_message`）或 CLI `--resume <id>`，避免反复新建会话。
